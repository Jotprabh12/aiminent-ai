# `public/`

Statically-served assets (available at the site root, e.g.
`public/images/og-default.png` → `/images/og-default.png`).

| Folder           | Contents                                                       |
| ---------------- | -------------------------------------------------------------- |
| `logos/`         | Aiminent AI wordmark / symbol (SVG). Added in a later session. |
| `icons/`         | Favicons, app icons, standalone SVG icons.                     |
| `illustrations/` | Workflow diagrams, isometric/automation SVGs (Chapter 3 §11).  |
| `backgrounds/`   | Gradient / texture backgrounds.                                |
| `images/`        | Raster imagery and Open Graph share images.                    |

**Guidelines:** prefer SVG; optimise raster images; illustrations must read
well on the dark theme (Chapter 7 §12 · Chapter 8 §8). No stock photography.
