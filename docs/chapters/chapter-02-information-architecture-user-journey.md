# Chapter 2 --- Information Architecture & User Journey

**Project:** Aiminent AI Website V1

------------------------------------------------------------------------

# 1. Objective

Design a website that feels like a premium SaaS company while
functioning as a high-converting sales funnel for AI automation
services.

Every page should naturally move visitors toward one of two actions:

-   Book Free Consultation
-   Schedule Live Demo

# 4. Homepage User Flow

1.  Hero grabs attention.
2.  Explain business pain points.
3.  Demonstrate automation visually.
4.  Present solutions as products.
5.  Build trust.
6.  Explain implementation process.
7.  Answer FAQs.
8.  Present a strong CTA.

------------------------------------------------------------------------

# 5. Consultation Funnel

Visitor clicks CTA →

Simple qualification form:

-   Name
-   Company
-   Email
-   Phone
-   Industry
-   Company Size
-   Biggest Challenge

Keep the form under one minute to complete to reduce friction.

After submission:

-   Thank-you page
-   Calendly scheduling
-   Confirmation email
-   CRM lead creation (future integration)

------------------------------------------------------------------------

# 6. Mobile Experience

The majority of prospects may visit from mobile.

Requirements:

-   Thumb-friendly navigation
-   Sticky CTA
-   Large touch targets
-   Optimized images
-   Fast page load
-   No horizontal scrolling

------------------------------------------------------------------------

# 7. Internal Linking Strategy

Every page should link to:

-   Relevant solution pages
-   Related packages
-   Contact page
-   Consultation booking
-   Homepage

Future placeholders should remain crawlable for SEO but clearly marked
as "Coming Soon."

# 9. Conversion Principles

Every page should include:

-   A clear value proposition
-   One primary CTA
-   One supporting CTA
-   Trust signals
-   Minimal distractions

Avoid clutter and unnecessary navigation depth.

------------------------------------------------------------------------

# 10. Acceptance Criteria

Claude Code should understand that:

-   The website is organized like a scalable SaaS platform.
-   Real Estate is the featured industry.
-   Future industries already have architectural placeholders.
-   The user journey is optimized around consultation bookings and
    demos.
-   Navigation, layout, and linking should remain modular and easy to
    expand.
